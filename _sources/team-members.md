# Team members

Each lab member has a personal badge on the papers they picked. Click a name to see their papers.

```{raw} html
<ul class="pl-team">
<li>👤 <a href="explore.html?badge=Hagai">Hagai</a></li>
</ul>
<p><a class="pl-edit-topics" href="http://rack-shamir6.cs.tau.ac.il:8765/members" target="_blank" rel="noopener"
   title="Add, rename or remove team members (library server, password)">Manage team members 🔒</a></p>
```

**Picking a paper:** tag it `lab-members/<your name>` in Mendeley, save it into your collection under
**lab-members** (for example with the Mendeley Web Importer), or use “Lab members” in a topic's paper editor
(Topics manager → Manage papers). All three stay in sync.
