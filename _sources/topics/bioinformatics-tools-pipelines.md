# Bioinformatics tools & pipelines

**Bioinformatics tools, web servers and pipelines that make genomic analyses accessible and reproducible.**
- Web servers for network-based analysis of omics data and drug repurposing.
  - [DOMINO web server](https://doi.org/10.1093/bioinformatics/btac067), [Drugst.One](https://doi.org/10.1093/nar/gkae388)
- Integrated platforms for transcriptome and gene-expression analysis.
  - [EXPANDER](https://doi.org/10.1186/1471-2105-6-232), [Expander protocol](https://doi.org/10.1038/nprot.2009.230), [EXPANDER integrated platform](https://doi.org/10.1016/j.jmb.2019.05.013)
- Pathway databases with visualization and analysis tools.
  - [SPIKE](https://doi.org/10.1186/1471-2105-9-110), [SPIKE database](https://doi.org/10.1093/nar/gkq1167)
- Workflow systems and community pipelines for reproducible analyses.
  - [Snakemake](https://doi.org/10.1093/bioinformatics/bts480), [Nextflow](https://doi.org/10.1038/nbt.3820), [nf-core](https://doi.org/10.1038/s41587-020-0439-x)
