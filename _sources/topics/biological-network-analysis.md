# Biological network analysis

**Interpreting genetic and genomic data using biological networks, such as [STRING](https://doi.org/10.1093/nar/28.18.3442) and [HuRI](https://doi.org/10.1038/s41586-020-2188-x).**
- Prioritizing disease genes.
  - [network propagation](https://doi.org/10.1371/journal.pcbi.1000641), [HotNet2](https://doi.org/10.1038/ng.3168)
- Propagating GWAS or rare-variant signals over networks.
  - [NAGA](https://doi.org/10.1016/j.isci.2019.05.025), [NetWAS](https://doi.org/10.1038/ng.3259)
- Identifying disease modules and pathways.
  - [DIAMOnD](https://doi.org/10.1371/journal.pcbi.1004120), [DOMINO](https://doi.org/10.15252/msb.20209593), [WGCNA](https://doi.org/10.1186/1471-2105-9-559)
