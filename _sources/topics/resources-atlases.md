# Resources: Atlases

  - [GTEx](https://doi.org/10.1038/ng.2653), [eQTLGen](https://doi.org/10.1038/s41588-021-00913-z)
- Functional genomic atlases.
  - [ENCODE](https://doi.org/10.1038/nature11247), [Roadmap Epigenomics](https://doi.org/10.1038/nature14248)
- Single-cell atlases.
  - [Human Cell Atlas](https://doi.org/10.7554/eLife.27041), [Tabula Sapiens](https://doi.org/10.1126/science.abl4896)
